# S40in Music

Официальная страница музыкального лейбла S40in — музыка, фантазия и бесконечность.

## Сайт
После успешного развёртывания GitHub Pages:
https://serega40in.github.io/S40inMusic/

## Обновление
Сайт — статический HTML/CSS/JS без сборки и без платных внешних сервисов. Изменения в `main` автоматически запускают GitHub Actions workflow `Deploy S40in Music to GitHub Pages`.

## Содержание
- Каталог музыкальных миров S40in, QUN, ЛКМ и TFT Home
- Ссылки на исходные композиции Suno
- Концепция фантастического музыкального произведения «Эйра»
- Поделиться сайтом в Telegram и скопировать ссылку

Важно: карточки — редакционная подборка. Перед коммерческим выпуском каждой композиции нужно отдельно проверить права и условия тарифа, на котором она создана.

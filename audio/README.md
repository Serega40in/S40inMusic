# S40in Music — audio files

Upload the final music files into this folder.

## Recommended upload
- Prefer MP3 for website playback and sharing.
- Use clear filenames, for example `roots-of-lightning-v1.mp3`.
- Keep cover art in `assets/art/`.
- After uploading, share the filenames or links so the website player can be connected to the actual files.

## Important
This folder is a place for source audio files. Uploading a file here does not automatically add it to the website player; the site page must link to each audio file explicitly.
